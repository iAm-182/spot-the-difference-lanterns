**Lantern Festival — Spot the Difference** is a complete, original spot-the-difference game in vanilla JavaScript and Canvas 2D. Three hand-drawn lantern-lit scenes — a night market, a harbor at dawn, and a mountain tea house — hang side by side in near-identical pairs. Find every difference before the lanterns burn down: 7 in the market, 8 at the harbor, 9 at the tea house, with a shrinking timer, hints, a score, and a three-star festival finale. Every picture, sound, and name is drawn and written from scratch in code — no libraries, no assets, no network requests.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 and click a difference on either picture. Press `H` for a hint, `M` to mute, `N` for the next level, `R` to restart, `1`/`2`/`3` to pick a level, and `Esc` for the menu.
